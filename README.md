# Achievement Engine · 成就存档社区仓库

独立的 Steam 游戏成就存档资源仓库。游戏和成就使用稳定 ID；无需攻略、作者账号或征集任务。所有通过 GitHub 身份验证、具有正常投稿权限的用户都可以在成就引擎中主动投稿。

仓库初始为空。游戏没有资源时显示正常的空仓库，不预建每款游戏的空目录。

- `catalog/index.json`：游戏索引。
- `catalog/games/steam/<AppID>.json`：已发布资源的公开元数据。
- `resources/<resourceId>.json`：不可变版本、兼容信息和下架状态。
- **GitHub Releases**：审核通过的 `.aesave` 文件；二进制不进入 Git 历史。
- `schemas/`：公开格式。

## 分享与下载

在成就引擎的游戏成就列表打开「社区存档」。上传前可预览将公开的字段和文件；文件先进入维护者服务的非公开隔离区，通过结构、哈希、隐私和恶意内容门禁后再审核发布。仓库不接收未经审核的存档附件或二进制 PR。

匿名用户可以浏览已发布资源；下载只导入本地社区库。恢复到游戏必须另外确认路径、退出游戏并成功建立恢复前保护点。文件校验通过不表示游戏载入或目标成就复现已经验证。

不要在 Issue、PR、仓库文件或说明中粘贴个人路径、Steam ID、登录令牌或真实存档。举报隐私问题时只提供资源 ID 与问题类别，由维护者通过受控通道处理。

见 [内容与审核政策](POLICY.md) 和 [维护部署](DEPLOYMENT.md)。
